## 一、与现有研究背景最接近的进展

### 1. σₖ 曲率流：无额外 pinching 的圆点收敛

Luo、Wei、Ruijia Zhang 与 Zhou 研究欧氏空间中以归一化 σₖ 为速度的收缩流。对 n≥3、2≤k≤n−1，任意光滑闭、连通、嵌入且严格凸的初始超曲面在有限时间收缩到一点；以消失点为中心并把平均宽度归一到 2 后，流在所有 Cʲ 范数中指数收敛到单位球。论文还给出主曲率与 (T−t)^(−1/(k+1)) 同阶的两侧估计、Type-I 上界、自相似收缩子刚性，以及熵亏损控制 Hausdorff 距离的定量稳定性。

核心机制不是预设 pinching，而是一个平移和缩放不变的熵。强化 Codazzi 不等式给出其单调性；熵上界控制内半径相对于平均宽度，耗散控制归一化速度的空间振荡，再补上自然尺度的曲率界和球附近谱稳定。这是本期与网页主人背景最直接的论文，也是其最新署名工作。

边界必须保留：这是 v1 预印本，定理要求严格凸性；不能外推到非凸流、弱解或一般环境空间。本期核到主定理、归一化、曲率尺度和熵链条，尚未逐行独立复证。

[arXiv:2611.03249](https://arxiv.org/abs/2611.03249)

### 2. 弱 k-Hessian 方程的 Wolff 势梯度估计

Liu、Ma 与 Zang 对 2≤k<n 的 proper weak k-convex 函数建立点态梯度估计：弱梯度由局部平均和 full Hessian measure 的截断 Wolff 势控制。由此，当 F_k[u]=f 且 f 属于临界 Lorentz 空间 L^(n/k,1/k) 时，u 局部 Lipschitz；对 F_k[u]=‖Du‖^p，则覆盖 0<p<nk/(n−k)。论文还给出反例，说明 Lorentz 的第二指标 1/k 和 p 的上界在完整弱解类中均尖锐。

这项结果的重要之处在于允许 Hessian 测度含奇异部分，因而比只处理光滑容许解的梯度估计更接近真正的弱解理论。但它属于梯度/Lipschitz 层级，不是 C² 或 Evans–Krylov 型二阶正则性。

[arXiv:2611.08184](https://arxiv.org/abs/2611.08184)

### 3. 非齐次 sum-Hessian 方程的全局曲率估计

Ma、Wang 与 Zhu 在闭星形超曲面上研究第一 Newton 变换 η=Hg−h 的方程 σ_k(λ(η))+ασ_(k−1)(λ(η))=f(X,ν)。对 α>0、2≤k≤n−1，在自然容许分支中，主曲率由 C¹ 几何、inf f 和 f 的 C² 范数等数据统一控制；附加球面 barrier 与径向单调条件后得到 prescribed-curvature 问题的存在唯一性。

关键代数是把非齐次算子写成高一维的 σ_k(λ₁,…,λ_n,α)，从而恢复椭圆性与凹性；失去齐次性产生的低阶项，再由 partial curvature estimate 吸收。k=n 端点未被主定理覆盖，不能从增广变量恒等式直接抹去。

[arXiv:2611.05032](https://arxiv.org/abs/2611.05032)

### 4. 双曲 Hessian–Neumann 问题与加权几何不等式

Weng 在双曲空间的 strictly static convex 域上解 σ_k(∇²u−ug)=f 的 Neumann 问题。边界条件决定唯一兼容常数 λ，k-admissible 解模静态势 V 唯一。比较不同 k 的兼容常数，并使用 k=2 的非线性 Neumann 势，作者得到加权 Minkowski、Heintze–Karcher 及相邻阶 Alexandrov–Fenchel 型不等式，等号刚性为测地球。

这里的几何条件不能弱化成普通严格测地凸性：论文给出 k=n 的不可解构形。它与上一期的双曲曲率商流形成静态—动态互补，但两者的指标范围、域条件和等号机制不能混为一个定理。

[arXiv:2611.03206](https://arxiv.org/abs/2611.03206)

## 二、Minkowski、弱流与复 Monge–Ampère

### 5. 毛细边界下的 L_p / Orlicz–dual Minkowski 流

本周两篇论文把 dual Minkowski 流推进到固定锐角接触的毛细超曲面。Hu、Hu 与 Yang 对偶的 normalized capillary L_p dual Minkowski 流证明：n≥2、θ∈(0,π/2)、pq≥0 时长期存在，并沿时间子列光滑收敛到稳态；p≠q 时，缩放极限解非归一化问题。Gao 则处理更一般的 φ(h)G(X)，允许非径向、非齐次位置权；在偶性加积分条件，或无偶性加双球冠 barrier 的两条路线下得到长期流和光滑解，额外严格缩放单调性给唯一性与 C^k 指数收敛。

这两篇工作共享球冠上的 Monge–Ampère/Robin 边界结构，但结论强度不同：前者主要是子列收敛，后者的全轨道指数收敛依赖额外单调条件。

[arXiv:2611.02732](https://arxiv.org/abs/2611.02732) · [arXiv:2611.02674](https://arxiv.org/abs/2611.02674)

### 6. 非光滑各向异性 Minkowski 流的弱适定性

Anastasi、Cagnetti 与 Morini 从 Wulff 邻域上的 oscillation perimeter 出发，研究可含晶体各向异性的非局部 Minkowski 型曲率运动。作者用 measure-valued nonlocal Cahn–Hoffman 场定义弱 super/subflow，从任意闭集得到弱演化；若初始 level set 的边界紧，比较原理给出 level-set flow 的存在唯一性。随相互作用尺度 r→0，变分弱流在可能 fattening 的限制下收敛到局部各向异性曲率流。

它为从光滑凸流走向晶体和弱界面提供了可操作桥梁，但不是 σₖ 圆点收敛的弱版本；“up to fattening”也必须保留。

[arXiv:2611.05245](https://arxiv.org/abs/2611.05245)

### 7. 齐次复 Monge–Ampère 的局部小数据高阶正则性

Yao 研究完整、可非紧 Kähler 流形 X 上 X×D 的齐次复 Monge–Ampère 方程。对有界 Perron envelope 弱解，如果 V⋐U 上有统一凸局部 Kähler 势、barrier threshold 满足 λR₀²≥16M，并且仅 U×∂D 上的边界数据足够小，则解在 V×D 局部光滑并满足定量 C^(k,β) 估计；U 外部的数据无需小。论文还讨论紧 Kähler 流形以及 ALE、ALF、ACH 端上的应用。

这不是对一般 HCMA 弱解的无条件升级；Perron envelope、局部小数据和 barrier 阈值都是实质输入。方法把 holomorphic-disc foliation、全局 subsolution、BMO 与 Nash–Moser–Zehnder 迭代组合起来，可作为实 Hessian 局部化正则性的参照模型。

[arXiv:2611.00736](https://arxiv.org/abs/2611.00736)

## 三、极小曲面与 AI 参与数学证明

### 8. 无穷远密度二的极小曲面分类声明

Bi 的 89 页 v1 预印本声明：若 M⊂R³ 是连通、properly embedded、无边界的极小曲面，且 H²(M∩B_R)/(πR²)→2，则 M 只能是 catenoid 或 singly periodic Scherk surface。作者说明这完成了 Meeks–Wolf 版本的 Scherk uniqueness conjecture。

论文明确披露：公开 LLM 用于发展数学论证、起草和修订稿件，作者承担全部责任。这一 disclosure 说明协作方式，不是独立验证。由于本次尚未审计从无穷远密度、端结构到最终分类的整条 89 页证明，台账暂记为 watch，而不是 established。

[arXiv:2611.08212](https://arxiv.org/abs/2611.08212)

## 四、AI 科研与验证工作流

### 9. Anthropic：科研会话实际集中在分析与写作

Anthropic 11 月 5 日发布对 207,049 个 Claude/Claude Code 消费者计划科研会话的聚合研究，样本期为 2026-08-02 至 09-30。报告称数学、统计和计算机科学的相对使用率较高；数据分析约占 Claude 科研会话三分之一、Claude Code 近一半，而 idea generation 与 data gathering 的实际使用较少。

这是一项基于分类器的观察性使用研究，不是随机对照生产率实验；消费者样本、分类器误差和无法观察未发表成果都限制外推。报告中的“产出可能翻倍或更高”属于情景模型，不应写成已经实现的科研增益。

[Anthropic 官方报告](https://www.anthropic.com/research/how-researchers-use-claude)

### 10. Microsoft PDD Kit：先固定意图，再证明代码符合规格

Microsoft Research 的 PDD Kit 把自然语言意图转成共享的 intent artifact 和 Verus 规格，用机器证明覆盖可形式化部分，对外部库、环境事实和界面行为使用测试，并把 Trusted Computing Base 显式交给人类确认。官方示例在约 5,000 行 Rust 全栈应用中验证登录核心。

它对数学科研 agent 的可迁移价值在于证据分层：命题量词、形式化核心、经验检查和外部可信边界必须分开。但当前原型只支持 Rust/Verus；“代码满足规格”也不等于“规格完整”，更不等于自然语言数学论文已被自动验证。

[Microsoft Research 官方说明](https://www.microsoft.com/en-us/research/blog/formally-verifying-agent-written-full-stack-web-apps-with-pdd-kit/)

### 11. OpenAI：用可执行证据逐级过滤 agent 候选

OpenAI 11 月 4 日披露 Linux 内核安全 agent 流水线：静态发现、动态复现、可利用性评估、补丁生成、人工审查。官方报告一次运行分析 2,308 个候选，动态复现 1,724 个漏洞，生成 948 个本地提权 exploit，API 成本约 121 万美元；最终材料包括 root-cause analysis、最小 crash PoC、候选补丁和 exploit。

这不是数学发布，统计也未被本次独立复现。它对科研 agent 的方法启示是：高召回探索之后需要可执行反例/证书、逐级过滤、成本记录与人类审查，而不能让同一个自然语言判断同时充当发现和验证。

[OpenAI 官方发布](https://openai.com/index/a-thousand-fewer-paths-to-root/)

OpenAI 的 openai/math 仓库本周没有新稿件或状态更新：公开 history 与 commits 显示最近提交仍为 2026-10-30。本期因此只更新核查日期，不人为补入旧内容。Google DeepMind 与 Anthropic 的其他本周官方发布中，未发现与本台账数学范围更直接且达到收录门槛的新材料。
